ABC TRACE & COLOR — OFFLINE APP TEST

IMPORTANT: This is a TEST build, not yet verified on iPad or iPhone.

The ZIP contains the original printable materials and a new Offline_Web_App folder.
To install on iPad or iPhone:
1. Upload ALL files inside Offline_Web_App to a GitHub Pages or Netlify website. Keep them together in the same folder.
2. In Safari, visit the HTTPS website while online and wait for the activity book to load completely.
3. Tap Share > Add to Home Screen > Add.
4. Open the new Home Screen icon while still online once, then switch on Airplane Mode and reopen it to test.
5. Test all letters, coloring, tracing, zoom, saving, and reopening.

After successful initial caching, the app is designed to work offline. Browser data can be cleared by iPadOS, so permanent offline availability and saved progress cannot be guaranteed. Progress stays on each device, not synced.

NOTE: Opening index.html directly from the Files app will NOT install the offline app. Service workers require an HTTPS website (or localhost for development).

Desktop: Chrome/Edge can install the site as an app. Safari support varies by platform.
Android: Open the HTTPS website in Chrome and use Install app/Add to Home screen.

Original files in this ZIP are retained for printable use.
